Вебхуки

Отправлять вебхук
Когда проиграно
%
Когда трек доиграет до указанного процента, приложение отправит его данные на адрес вебхука
Пример отправляемых данных 
{
  "timestamp": "2025-08-12T14:30:45.123Z",
  "artist": "Artist Name",
  "track": "Track Title", 
  "duration": 240,
  "trackArt": "https://example.com/artwork.jpg",
  "originUrl": "https://soundcloud.com/track-url"
}
