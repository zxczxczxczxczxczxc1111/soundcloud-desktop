# SoundCloud Desktop

Клиент SoundCloud для Windows с Discord Rich Presence, темами, плагинами, прокси и блокировкой рекламы.

Основан на [soundcloud-rpc](https://github.com/richardhbtz/soundcloud-rpc) Ричарда Хабицройтера, коммит `bc3b3de6c19175c614712e09c9af68bd1c226396`. Лицензия MIT, исходное уведомление об авторских правах сохранено.

## Состояние

Версия 0.1.0 находится в разработке. Сборки предназначены для проверки. Полная проверка воспроизведения, входа и длительной работы ещё не завершена.

## Сборка

Требуются Windows x64 и Node.js 24.

```powershell
npx pnpm@10.34.5 install --frozen-lockfile
npx pnpm@10.34.5 typecheck
npx pnpm@10.34.5 lint
npx pnpm@10.34.5 test
npx pnpm@10.34.5 test:electron
npx pnpm@10.34.5 build-win
npx pnpm@10.34.5 build-win-ptb
```

Для защищённого воспроизведения используется Castlabs Electron с Widevine. Перед сборкой установите Python и зарегистрируйтесь в бесплатном [Castlabs EVS](https://github.com/castlabs/electron-releases/wiki/EVS):

```powershell
python -m pip install castlabs-evs==1.3.2
python -m castlabs_evs.account signup
```

Сборка автоматически получает и проверяет VMP-подпись. При ошибке подписи сборка останавливается. Для тестовой сборки без подписи можно явно задать `SKIP_VMP_SIGNING=true`; CI использует этот режим. VMP не является цифровой подписью издателя Windows, поэтому SmartScreen может показать предупреждение.

## Использование

F1 открывает настройки. Приложение использует отдельный профиль и не заменяет исходный клиент SoundCloud. Обновление выполняется вручную установщиком или заменой portable-сборки. Portable хранит профиль в папке `soundcloud-desktop-data` рядом с EXE. Пароли прокси защищены средствами Windows и могут потребовать повторного ввода при переносе на другой компьютер.

Значок GitHub в активности Discord открывает репозиторий приложения. Его можно отключить в настройках Discord внутри клиента. Репозиторий приватный, для открытия нужен доступ.

Плагины выполняют пользовательский код. Включайте только плагины, которым доверяете.

## Диагностика

При проблеме откройте настройки по F1 и нажмите «Сохранить журнал» в разделе «Диагностика». Полученный `.log` можно отправить для разбора ошибки.

Журнал остаётся на компьютере. В нём есть версия сборки, ошибки, состояние воспроизведения, нагрузка, события сна и сбои процессов. Названия треков, адреса, пароли, токены и тексты сообщений в него не записываются. Показатели собираются раз в 30 секунд; три сменяемых файла занимают примерно до 6 МБ.
