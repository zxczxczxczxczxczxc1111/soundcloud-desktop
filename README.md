# SoundCloud Desktop

Клиент SoundCloud для Windows с Discord Rich Presence, темами, плагинами, прокси и блокировкой рекламы.

Основан на [soundcloud-rpc](https://github.com/richardhbtz/soundcloud-rpc) Ричарда Хабицройтера, коммит `bc3b3de6c19175c614712e09c9af68bd1c226396`. Лицензия MIT, исходное уведомление об авторских правах сохранено.

## Состояние

Версия 0.1.0 находится в разработке. Готовых проверенных сборок пока нет.

## Сборка

Требуются Windows x64 и Node.js 24.

```powershell
npx pnpm@10.34.5 install --frozen-lockfile
npx pnpm@10.34.5 typecheck
npx pnpm@10.34.5 test
npx pnpm@10.34.5 build-win
npx pnpm@10.34.5 build-win-ptb
```

Для защищённого воспроизведения используется Castlabs Electron с Widevine. Готовый пакет требует проверки VMP-подписи и воспроизведения.

## Использование

F1 открывает настройки. Приложение использует отдельный профиль и не заменяет исходный клиент SoundCloud. Обновление планируется вручную установщиком или заменой portable-сборки.

Плагины выполняют пользовательский код. Включайте только плагины, которым доверяете.
